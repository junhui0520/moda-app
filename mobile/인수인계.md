## 2. 배포 서버 & 로컬 실행 방법

- **Mock 배포 서버 (Railway, 24시간 운영 중)**:
  - API Base URL: `https://moda-app-production.up.railway.app`
  - Swagger 문서: `https://moda-app-production.up.railway.app/swagger-ui/index.html`
  - 상태: `aiMode: "mock"`, `chatMode: "mock"` (헤더 없이 호출 시 `oval` + `standard` 정상 응답)
- **로컬 실행 명령어** *(Windows PowerShell에서는 보안 정책 때문에 `npm.cmd`, `npx.cmd` 사용)*:
  ```powershell
  cd mobile
  npm.cmd install        # 새 PC(노트북 등)에서 처음 받을 때만 실행
  npm.cmd run start      # 같은 Wi-Fi 아이폰 Expo Go 실행
  npx.cmd expo start --tunnel  # 다른 Wi-Fi/5G 팀원 아이폰 Expo Go 공유
  npm.cmd run web        # PC 브라우저 미리보기
  ```
- **앱 내 테스트 설정**: 시작 화면 우측 상단 `[TEST]` 버튼 → Base URL 변경, 헬스체크, Mock 헤더(`X-Mock-Face-Shape`, `X-Mock-Body-Type`, `X-Mock-Unusable`, `X-Mock-Borderline`, `X-Mock-Body-Minimal`, `X-Mock-Delay-Ms`) 원클릭 제어 가능.

## 4. Mobile 필수 구현 규칙 (구현 반영 완료 · 유지 필수)

1. **한글 문구·유형명 하드코딩 금지**: 라벨, 유형명(`TYPE-01`~`TYPE-24`), 추천 이유, 경고 문구, `disclaimer`, 챗봇 `welcomeMessage` 모두 API 응답 그대로 렌더링.
2. **외모 평가 배제 (R-11)**: 응답의 `score`(점수·별점·%) 및 BMI·몸무게 수치는 화면에 절대 노출 금지(`rank`, `reasons`만 사용).
3. **`usable: false` vs `503/504` 분기 구분**:
   - `usable: false` (HTTP 200): 경고창 + **재촬영만 허용** ("직접 선택하기" 노출 금지, 다음 이동 불가).
   - `503 AI_SERVER_UNAVAILABLE` / `504 AI_TIMEOUT`: `[재시도]` + **`[직접 선택하기]` 노출** → ⑦ `PATCH /profile`.
4. **체형 상세 Optional 필드 & 얼굴 `aiReason` 처리**: `null` / `[]`인 항목은 빈 문구 없이 자연스럽게 숨김.
5. **챗봇 규칙 (v1.2)**:
   - `429 CHAT_TURN_LIMIT_EXCEEDED` / `remainingTurns === 0` → 입력창·추천 칩 비활성화.
   - `503 CHAT_SERVER_UNAVAILABLE` / `504 CHAT_TIMEOUT` → 입력 문장 유지 + `[다시 보내기]` (턴 차감 없음).
6. **사진 업로드 & 프라이버시 (R-01)**: `quality: 0.7`, `FormData` 전송 시 `Content-Type` 직접 지정 금지, 숨김 초기화(로고 3초 길게 누르기) 시 ⑧ `DELETE` 호출 및 로컬 URI 삭제.
7. **세션 만료 (`404` / `410`)**: 로컬 상태 초기화 후 `Start` 화면으로 이동.

## 6. AI 어시스턴트 참고 사항

- 사용자는 **Mobile 담당(이상현)**이며, AI/백엔드 내부 깊은 구현보다는 **Mobile 구현에 필요한 내용 중심**으로 소통하는 것을 선호함.
- 설명 시 너무 어렵지 않게 작성하고, **다소 어려운 개발 용어는 섹션 아래에 간단한 용어 풀이**를 함께 적어줄 것.
- 팀원 전원 iPhone 사용: 개발/시연은 **Expo Go + `--tunnel`**, PC 꺼놔도 볼 수 있는 링크가 필요하면 **웹 버전 무료 배포** 활용.
